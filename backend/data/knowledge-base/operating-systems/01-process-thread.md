# 进程与线程
## 进程的定义
进程是程序关于某个数据集合的一次运行活动，是系统进行资源分配和调度的基本单位。它由程序段、数据段和进程控制块 PCB 组成，PCB 保存标识符、状态、优先级、程序计数器与资源清单等信息。
## 进程的特征
进程具有动态性、并发性、独立性和异步性。动态性指进程有创建、运行和消亡的生命周期；独立性指进程拥有独立的地址空间，未加保护时一个进程不能直接访问另一个进程的内存。
## 进程控制块
PCB 是进程存在的唯一标志，操作系统通过 PCB 管理进程。PCB 通常包含进程标识、处理机状态（寄存器现场）、调度信息（优先级、状态）和资源信息（打开文件、内存指针）。
## 线程的引入
线程是进程内的执行流，是处理机调度的基本单位。同一进程内的多个线程共享代码段、数据段和打开文件等资源，但各自拥有独立的栈和寄存器上下文，因此线程切换开销远小于进程切换。
## 线程与进程的区别
进程是资源分配单位，线程是调度单位；进程切换需要切换地址空间而线程切换只需切换栈与寄存器；进程间通信需要系统调用或共享内存，线程间可直接读写共享数据。
## 多线程模型
用户级线程由线程库在用户空间调度，内核不可见；内核级线程由内核调度，能真正并行；多对多模型把多个用户线程映射到多个内核线程，兼顾灵活性与并行度。
## 并发与并行
并发是逻辑上同时推进、实际可能交替执行；并行是多个处理机同时执行。单核上多个进程通过快速切换实现并发，多核上多个线程可真正并行运行。
## 典型问题
创建过多进程会带来 PCB 与页表等内存开销，创建线程过多会引入同步与上下文切换开销。应根据任务性质选择进程或多线程模型，并限制并发规模避免调度开销吞噬收益。
