# 内存管理
## 地址空间与重定位
逻辑地址是程序视角的地址，物理地址是主存实际地址。地址变换（重定位）把逻辑地址映射为物理地址，可由装入时静态完成或运行时由硬件动态完成。
## 连续分配
单一连续分配简单但利用率低；固定分区产生内部碎片；动态分区按需分配，通过首次适配、最佳适配、最坏适配等算法选择空闲区，产生外部碎片并可紧凑消除。
## 分页存储
把逻辑地址空间和物理内存都分成固定大小的页与页框，页表记录逻辑页到物理页框的映射。逻辑地址拆成页号和页内偏移，通过页表查询得到物理地址。
## 页表与快表
多级页表用层次结构解决页表过大问题。快表（TLB）缓存最近使用的页表项，利用局部性原理加速地址变换；命中时无需访问内存页表。
## 分段存储
按程序的逻辑单元分段，每段有独立的段号、段长与段内偏移。段表记录各段的基址与长度，分段有利于共享与保护，符合模块化编程，但会产生外部碎片。
## 段页式存储
先按段划分再在段内分页，综合分段逻辑清晰与分页无外部碎片的优点。地址由段号、段内页号和页内偏移组成，需要段表与页表两次映射，变换开销较大。
## 内存保护
越界检查确保访问不超出分配范围，越权检查防止非法操作。分页中页表项的保护位可标记只读；分段中段表长度字段用于越界检测。
## 典型问题
计算物理地址时先根据页号查页表得到页框号，再拼上页内偏移。注意页表项可能缺页或被保护，多级页表需按级别逐层解析。
