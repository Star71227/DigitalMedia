# 磁盘与I/O管理
## 磁盘结构
磁盘由多个盘面组成，每个盘面划分为磁道，磁道再划分为扇区。访问时间由寻道时间、旋转延迟和传输时间构成，其中寻道时间通常占比最大。
## 先来先服务磁盘调度
FCFS 按请求到达顺序服务，公平且实现简单，但磁头可能大幅来回移动，平均寻道距离大，性能差。
## 最短寻道时间优先
SSTF 每次选择距当前磁道最近的请求，平均寻道距离小，但可能使远离磁头一侧的请求长期得不到服务，产生饥饿。
## 扫描算法
SCAN（电梯算法）磁头沿一个方向移动服务，到边界后反向；LOOK 是到最远请求即反向。SCAN 避免了饥饿，但边界处磁道被访问的频率可能较高。
## 循环扫描
CSCAN 磁头单向移动，到边界后直接回到起点再单向服务，使各磁道响应更均匀；CLOOK 回到最远请求处。适合负载较均匀的场景。
## I/O 控制方式
程序查询由 CPU 不断轮询状态，效率低；中断方式在设备就绪时通知 CPU，减少忙等；DMA 由控制器直接与内存交换数据，CPU 只在开始与结束时介入；通道进一步分担控制。
## 缓冲与 SPOOLing
缓冲用于平滑设备与 CPU 的速度差异，双缓冲可并行处理；SPOOLing 用磁盘缓冲区把独占设备虚拟成共享设备，实现脱机输入输出。
## 典型问题
计算寻道时间时按调度算法排序请求磁道，累加相邻磁道差的绝对值。注意区分电梯算法是否需要到达物理边界，以及旋转延迟与传输时间是否计入。
