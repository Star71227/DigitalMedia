# 处理机调度
## 调度层次
作业调度（高级调度）决定哪些后备作业进入内存；进程调度（低级调度）决定哪个就绪进程获得 CPU，频率最高；中级调度进行内存与外存的换入换出，调节多道程序度。
## 调度性能指标
周转时间等于完成时间减到达时间，带权周转时间等于周转时间除以运行时间。平均周转时间越小、平均等待时间越短，说明调度对用户越友好。
## 先来先服务
FCFS 按到达顺序服务，实现简单、不可抢占，但长作业会让后续短作业长时间等待，产生“护航效应”，对交互式任务不友好。
## 短作业优先
SJF 选择估计运行时间最短的作业，能得到最小平均等待时间，但需要预知运行时间，且长作业可能饥饿。可抢占的 SJF 又称最短剩余时间优先。
## 时间片轮转
RR 给每个就绪进程固定时间片，轮流执行。时间片太大会退化为 FCFS，太小会增加上下文切换开销。适合分时系统，保证交互响应。
## 优先级调度
按优先级选择进程，可抢占或不可抢占。固定优先级可能让低优先级进程饥饿，可通过老化（等待越久优先级越高）缓解。优先级反转问题需借助优先级继承解决。
## 多级反馈队列
设置多个优先级队列，高优先级队列时间片短、低优先级长；新进程进入最高队列，用完时间片降到下一队列。它综合了短作业优先与轮转的优点，能自适应不同任务。
## 典型问题
比较调度算法时先算每个进程的完成时刻，再求周转时间与等待时间。注意抢占点：新进程到达或时间片耗尽时，当前进程可能被更强优先级的进程取代。
