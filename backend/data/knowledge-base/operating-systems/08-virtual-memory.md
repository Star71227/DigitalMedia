# 虚拟内存与页面置换
## 虚拟内存的思想
虚拟内存把磁盘等外存当作主存的扩展，程序只需部分驻留内存即可运行，使逻辑地址空间可以大于物理内存。它建立在程序访问的局部性原理之上。
## 局部性原理
时间局部性指刚访问过的位置很可能再次被访问；空间局部性指相邻位置很可能被访问。正是局部性使少量驻留页面就能维持较高命中率，虚拟内存才可行。
## 请求分页
页面不在内存时产生缺页中断，系统从外存调入所需页面。若内存无空闲页框，则按置换算法淘汰一页；被淘汰页若被修改过需写回外存。
## 最佳置换算法
OPT 淘汰将来最久不会被访问的页面，缺页率最低，但需要预知未来访问序列，无法实现，只能作为评价其他算法的理论下界。
## 先进先出置换
FIFO 淘汰驻留时间最长的页面，实现简单但有 Belady 异常：增加物理块数反而可能使缺页次数增加。
## 最近最久未使用
LRU 淘汰最长时间未被访问的页面，较好利用时间局部性，但需硬件或堆栈支持记录访问次序，实现成本高；常用近似算法如 CLOCK（时钟）替代。
## 缺页率与抖动
缺页率过高会使系统把大量时间花在页面换入换出上，处理机利用率反而下降，称为抖动。可通过增加物理内存、降低多道度或改进置换算法缓解。
## 典型问题
给访问序列与页框数求缺页次数时，按算法逐次判断页面是否在内存。注意首次装入也算缺页，OPT 看未来、LRU 看过去、FIFO 看驻留顺序。
