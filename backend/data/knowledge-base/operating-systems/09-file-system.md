# 文件系统
## 文件的逻辑结构
无结构文件是字节流；有结构文件分为顺序文件、索引文件与索引顺序文件。逻辑结构决定用户如何组织与访问数据，物理结构决定数据在磁盘上的存放方式。
## 文件的物理结构
连续分配访问快但易产生外部碎片；链接分配通过指针串联磁盘块，无外部碎片但随机访问慢；索引分配用索引块保存全部块号，支持随机访问，索引块本身有开销。
## 目录结构
单级目录无法重名；两级目录区分用户；多级目录（树形）便于组织与共享。目录项记录文件名与位置信息，硬链接共享同一索引节点，软链接保存目标路径。
## 索引节点
inode 保存文件的元数据（权限、大小、时间戳、数据块指针），与文件名分离。多级间接指针使小文件用直接指针高效访问，大文件通过间接指针扩展容量。
## 空闲空间管理
空闲表、空闲链表、位示图、成组链接是常见方法。位示图每位表示一个盘块是否空闲，定位简单，适合随机分配。
## 文件共享与保护
访问控制列表与用户权限位（读、写、执行）控制访问。文件系统还需处理一致性：崩溃后通过日志或文件系统检查（如 fsck）恢复元数据。
## 典型问题
计算文件最大容量时，按直接、一级间接、二级间接指针逐级累加可寻址块数，再乘块大小。注意每个间接指针项占用的字节数与块大小的关系。
