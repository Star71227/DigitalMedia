# 数组
## 一维数组
一维数组是相同类型元素的连续存储，定义如 int a[10];。下标从 0 开始，第 i 个元素为 a[i]，共 n 个元素则下标范围 0 到 n-1。
## 数组初始化
定义时可整体初始化 int a[5] = {1,2,3}; 未列出的元素补 0。不指定长度时由初值个数决定长度。数组不能整体赋值，只能逐个元素赋值。
## 二维数组
二维数组按行存储，int a[2][3]; 表示 2 行 3 列。初始化可省略行数但列数不能省。元素按 a[行][列] 访问，内存中按行优先连续存放。
## 数组名与首地址
数组名在表达式中（除 sizeof 与取地址外）退化为指向首元素的指针，值是首元素地址。a 与 &a[0] 值相同，但 &a 的指针类型指向整个数组。
## 越界访问
访问 a[n] 或更远是越界，属未定义行为，可能读到或改坏相邻内存而不报错。C 不做边界检查，程序员必须自己保证下标合法。
## 数组作函数参数
数组作参数时退化为指针，函数内 sizeof 得到的是指针大小而非数组大小，因此通常需额外传长度。可用指针参数接收一维数组。
## 典型问题
计算数组占用字节数（元素数 × sizeof 元素）与下标范围；二维数组按行优先推算某元素在内存中的位置；判断越界与首地址相关结论。
