# 函数
## 函数的定义与声明
函数由返回类型、函数名、参数表与函数体组成。调用前需先声明（原型）或定义，声明给出返回类型、名字与参数类型，让编译器检查调用。
## 调用与返回
函数通过函数名加实参调用，return 返回值给调用者，函数体执行到 return 或末尾即返回。返回值类型必须与声明一致。
## 形参与实参
形参是函数定义中的参数，实参是调用时传入的值。C 的参数传递是“按值传递”，实参值复制给形参，函数内修改形参不影响实参。
## 传址与指针参数
要修改调用方的变量，需传变量的地址，函数用指针形参接收，通过解引用修改实参。scanf 传地址、交换两数等都用这种方式。
## 递归
函数直接或间接调用自身。递归需有终止条件（基线）与逐步逼近终止的递推。递归思路清晰但可能带来栈开销，尾递归可被优化。
## 变量作用域
局部变量在函数内，块外不可见；全局变量在所有函数外，作用域从定义到文件尾。static 局部变量在多次调用间保持值。
## 典型问题
判断按值传递还是按地址传递能否修改实参；分析递归的执行过程与返回路径；区分局部、全局与 static 变量的生命周期与可见性。
