# 运算符与表达式
## 算术运算符
加 +、减 -、乘 *、除 /、取余 %。整数除法截断小数部分，取余仅用于整数。注意负数的除法与取余方向由实现决定，通常向零截断。
## 赋值运算符
= 把右值赋给左值，复合赋值 +=、-=、*=、/=、%= 先运算再赋值。赋值表达式的值是被赋的值，可连续赋值 a = b = c。
## 自增自减
++ 与 -- 使变量加一或减一。前缀先自增后取值，后缀先取值后自增。自增用于表达式时要注意副作用与求值顺序。
## 关系与逻辑运算符
关系运算 <、<=、>、>=、==、!= 结果为 0 或 1；逻辑运算 &&、||、! 有短路特性：&& 左侧为假则不算右侧，|| 左侧为真则不算右侧。
## 位运算与移位
&、|、^、~ 按位操作，<<、>> 移位。左移等价乘 2，右移对有符号数可能是算术右移或逻辑右移。位运算常用于掩码、置位与清除。
## 优先级与结合性
优先级从高到低大致为：后缀、单目、乘除、加减、移位、关系、相等、按位、逻辑、条件、赋值、逗号。不清楚时用括号显式限定，避免歧义。
## 类型转换
混合运算时低类型向高类型提升（整型提升、算术转换）。强制转换 (类型) 表达式可显式转换，但可能损失精度或改变符号解释。
## 典型问题
计算表达式值时要严格按优先级与结合性，特别注意自增自减的前后缀、短路求值与整数除法截断；避免在一条语句中对同一变量多次自增。
