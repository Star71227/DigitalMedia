# 数据类型与变量
## 基本数据类型
C 的基本类型有整型 int、字符型 char、单精度 float、双精度 double 等。整型还分 short、long、long long，可用 signed 或 unsigned 修饰表示有无符号。
## 变量的定义
变量必须先声明后使用，声明指定类型与名字，如 int a;。变量名是标识符，由字母、数字和下划线组成，不能以数字开头，不能与关键字冲突。
## 变量的初始化
定义时可赋初值，未初始化的局部变量值不确定（垃圾值），全局与静态变量默认初始化为 0。读取未初始化变量是未定义行为。
## 常量
字面量如 100、3.14、'A'；const 修饰只读变量；#define 定义符号常量。const 变量仍占存储但不可被修改。
## 进制与补码
整数字面量支持十进制、八进制（0 前缀）与十六进制（0x 前缀）。负数在机器中以补码存储，补码使加减统一、零唯一表示。
## sizeof 与取值范围
sizeof 返回类型或变量占用的字节数，各类型字节数因平台而异。取值范围由字节数和有无符号决定，做题时注意不同环境 int 可能为 2 或 4 字节。
## 转义字符
换行 \n、制表 \t、反斜杠 \\、单引号 \'、空字符 \0 等转义字符用反斜杠表示，'\0' 是字符串结束标志，ASCII 值为 0。
## 典型问题
判断变量取值范围、sizeof 结果与类型字节数；区分字符常量 'A' 与字符串 "A"（后者含 '\0'）；注意整型溢出与符号扩展。
