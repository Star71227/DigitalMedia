# 指针
## 指针与地址
指针是保存内存地址的变量，类型如 int *p;。& 取变量地址，* 解引用访问指针指向的对象。指针类型决定解引用时读取多少字节与如何解释。
## 指针的初始化
指针必须指向合法内存才能解引用。未初始化的指针是野指针，解引用属未定义行为。可用 NULL 表示空指针，解引用空指针会崩溃。
## 指针运算
指针加整数按所指向类型的大小移动，p+1 使地址增加 sizeof(*p)。指针相减得到元素个数差，指针比较通常在数组范围内才有意义。
## 指针与数组
数组名可作指针用，*(p+i) 等价于 p[i]，指针可用下标访问。指向数组的指针遍历元素既可用下标也可用指针递增。
## 指针作函数参数
函数要修改调用方变量时传地址，函数内用指针解引用修改。这实现了“传址”效果，但本质仍是值传递——传递的是地址值。
## 二级指针与指针数组
二级指针保存指针的地址，如 char **p;。指针数组是元素为指针的数组，如 int *arr[5];，常与字符串数组、命令行参数 argv 相关。
## 函数指针
指向函数的指针保存函数入口地址，可用于回调、把函数作为参数传递。声明如 int (*f)(int, int)，调用为 f(a, b)。
## 典型问题
分析指针加减的实际字节偏移；判断解引用与取地址的组合含义；区分指针数组与数组指针（int *a[5] 与 int (*a)[5]）。
