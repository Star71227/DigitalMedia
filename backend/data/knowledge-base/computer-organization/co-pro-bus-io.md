# 总线与 I/O 系统

## 总线的基本概念与特点
总线是连接计算机各部件的一组公共信号线，是多个部件之间传送信息的共享通道。采用总线结构可以大幅减少连线数量、便于系统的模块化设计与扩充，但也带来了两个固有限制：一是分时共享，同一时刻只允许一个部件向总线发送信息，其他部件只能接收，因此必须由总线仲裁来决定使用权；二是带宽共享，所有部件竞争同一份传输能力，总线容易成为系统性能瓶颈。总线仲裁分为集中式（由中央仲裁器统一裁决，具体有链式查询、计数器定时查询与独立请求三种方式）与分布式（无中央仲裁器，各设备按协议自行裁决）两大类，仲裁方案的选择要权衡优先级是否可变、响应速度、所需信号线数、对故障的敏感程度与扩充的方便性。总线的性能由宽度、频率、协议与仲裁方式共同决定。

## 数据总线、地址总线、控制总线
按传送信息的类型，总线分为三组。数据总线用于在 CPU、主存与 I/O 设备之间传送数据与指令，是双向的，其宽度决定一次能并行传送的二进制位数（常见 8、16、32、64 位），也直接影响总线带宽。地址总线用于指定数据总线上的数据对应于哪个存储单元或 I/O 端口，由 CPU 或总线主设备单向输出，其宽度决定最大可寻址空间，例如 32 位地址总线可寻址 2^32 = 4GB。控制总线传送各种控制与状态信号，包括读/写命令、存储器请求、I/O 请求、中断请求与响应、总线请求与允许、时钟与复位、握手应答等，方向依信号而定，种类最复杂。

## 总线的层次与传送方式
按所处层次，总线可分为：片内总线（CPU 芯片内部连接寄存器与 ALU 的总线）、系统总线（连接 CPU、主存与 I/O 接口的总线，又可细分为主存总线、I/O 总线与 DMA 总线）、通信总线（计算机之间或计算机与外部设备之间，如 USB、RS-232、以太网）。按传送方式分为并行总线与串行总线：并行总线一次传送多位，线数多、成本高，且各线之间存在信号偏斜与串扰问题，只适合短距离高速传输，如 PCI；串行总线一次只传一位，线数少、成本低、抗干扰能力强，可通过差分信号与多通道聚合实现极高的总带宽，如 PCI Express、USB、SATA，是现代总线的主流方向。

## 总线性能指标与带宽计算
总线的主要性能指标有：总线宽度，即数据线的根数；总线工作频率，即总线时钟频率；总线带宽，即单位时间内可传送的最大数据量，单位为 B/s；总线周期，即完成一次总线操作所需的时间。在理想情况下有 总线带宽 = 总线宽度（字节） × 总线工作频率。例如 32 位宽、66MHz 的总线，带宽 = 4B × 66MHz = 264 MB/s。若一个总线周期包含多个时钟（如需要 2 个时钟才完成一次数据传送），则带宽要除以每周期时钟数：64 位宽、100MHz 且每 2 个时钟传送一次时，带宽 = 8B × 100MHz / 2 = 400 MB/s。此外，总线复用指用同一组信号线分时传送地址与数据，可减少引脚但会降低速度，常见于地址/数据复用的处理器总线。

## 链式查询方式
链式查询只用三根线完成仲裁：总线请求线 BR（各设备共用）、总线允许线 BG（沿菊花链依次串接各设备）和总线忙线 BS。当某设备需要总线时拉高 BR，仲裁器收到后发出 BG；BG 沿链依次传递，最先收到 BG 的设备若正在请求则截获 BG 获得总线使用权并置 BS 有效，BG 不再向后传递。它的优点是所需线数极少（3 根）、结构简单、扩充容易；缺点是优先级完全由物理位置决定（离仲裁器越近优先级越高）且不可改变，一旦链上某设备故障，BG 无法继续传递，其后的所有设备都被"饿死"，可靠性较差。

## 计数器定时查询方式
计数器定时查询用一组设备地址线代替菊花链：仲裁器内的计数器在收到总线请求后开始计数，计数值经地址线广播给所有设备，与自身设备号相符且正在请求总线的设备获得使用权并停止计数。所需线数为总线请求线、总线忙线加 ⌈log2 n⌉ 根地址线（n 为设备数），共约 ⌈log2 n⌉ + 2 根。它的优点是优先级灵活：计数器每次从 0 开始则设备号小的优先，从上次停止处继续则各设备机会均等（循环优先级）。相比链式查询，某设备故障只影响自身，不影响其他设备获得总线。缺点是需要地址译码与比较电路，仲裁过程占用若干时钟周期，速度比独立请求慢。

## 独立请求方式
独立请求方式为每个设备分别设置一条总线请求线 BR_i 和一条总线允许线 BG_i：设备各自向仲裁器提出请求，仲裁器内部有优先级排队电路，直接选中优先级最高者并向其发出允许信号。它的优点是响应速度最快（不需要逐个查询，裁决几乎在一个时钟内完成）、优先级可灵活编程、对故障不敏感；缺点是信号线数量随设备数线性增长（2n 根），当设备很多时连线成本与控制逻辑复杂度迅速上升，只适合设备数量较少的系统。实际的高性能总线（如 PCI）多采用独立请求加集中仲裁器的方案。

## 总线定时：同步定时
总线定时规定了总线操作的时间关系，即地址、数据与控制信号在什么时候有效、什么时候可以采样。同步定时由统一的时钟信号控制，所有设备都在时钟沿采样，一次总线操作在固定数量的时钟周期内完成（例如固定 2 个时钟：第一个时钟送地址，第二个时钟完成数据传送）。它的优点是协议简单、控制逻辑少、传输速度快、便于高速流水化传输；缺点是整个系统必须按最慢设备的速度设计，快速设备的能力被浪费，而且一旦时钟周期确定就无法适应不同速度的设备，也不适合长距离传输（时钟偏斜会破坏同步）。

## 总线定时：异步握手与半同步
异步定时不用统一时钟，而靠请求（Request）与应答（Acknowledge）信号进行握手，各设备按自己的速度工作，因此适应性好、可靠性高，适合连接速度差异大的设备。按握手信号撤销条件的不同分为三种：不互锁方式中主设备发出请求后经一段时间自动撤销，从设备收到请求后经一段时间自动给出并撤销应答，速度最快但可靠性最低；半互锁方式中主设备必须收到应答才撤销请求，而从设备的应答自动撤销；全互锁方式中主设备收到应答后才撤销请求，从设备检测到请求撤销后才撤销应答，最可靠但速度最慢。异步定时的缺点是控制复杂、每传送一次数据都要经过一个完整的握手过程，因此总带宽低于同步定时。半同步定时则在同步定时的基础上增设一条等待（WAIT）信号线：慢速设备通过拉低 WAIT 请求延长总线周期，使系统兼具同步的简单与异步的灵活。

## 常见总线标准
常见的系统总线与设备总线标准包括：ISA（16 位、8MHz，早期的工业标准总线，现已淘汰）；PCI（32/64 位并行总线，33/66MHz，支持即插即用与独立请求仲裁，33MHz/32 位时带宽约 133MB/s）；AGP（专为显卡设计，逐步被 PCIe 取代）；PCI Express（PCIe，点对点串行差分总线，全双工，每通道单向速率随版本提升，Gen1 为 2.5GT/s、Gen2 为 5GT/s、Gen3 为 8GT/s、Gen4 为 16GT/s、Gen5 为 32GT/s，可用多通道并行聚合带宽，并采用 8b/10b 或 128b/130b 编码）；USB（支持热插拔与总线供电，USB 2.0 为 480Mbps，USB 3.x 提升到 5/10/20Gbps）；SATA（串行硬盘接口）；以及片内的 I²C、SPI 与 SoC 常用的 AXI 总线。

## I/O 接口的功能与组成
I/O 接口是 CPU 与外部设备之间的桥梁，其功能包括：数据缓冲，用寄存器暂存数据以实现 CPU 与慢速设备之间的速度匹配；数据格式转换，完成串行与并行之间的转换、电平与码制的转换；通信控制，接收 CPU 发来的命令并转达给设备，同时把设备的状态（就绪、忙、出错）反馈给 CPU；地址译码与设备选择，根据地址与控制信号判断本次操作是否针对本接口；错误检测（如奇偶校验）；以及向 CPU 提出中断请求。一个典型的接口由数据寄存器（数据端口）、状态寄存器（状态端口）、控制寄存器（控制端口）、地址译码与控制逻辑、中断控制逻辑组成，端口是接口中可被 CPU 直接访问的寄存器。

## I/O 端口与编址方式
I/O 端口的编址有两种方式。统一编址（存储器映射 I/O）把 I/O 端口与主存单元放在同一个地址空间中，用访问主存的指令访问端口，因此不需要专门的 I/O 指令、指令种类丰富、寻址方式多，缺点是占用了主存地址空间，且程序不易区分访存与访问端口。独立编址（I/O 映射）为 I/O 端口单独开辟一个地址空间，用专门的输入输出指令（如 x86 的 IN/OUT）访问，并用专门的 I/O 读写控制信号与存储器读写信号区分，不占用主存空间、程序可读性好，缺点是需要额外的指令、访问方式受限（通常只能用累加器）。两种方案都属于常见的考试与设计内容，选择取决于指令系统与硬件成本的整体考虑。

## 程序查询方式
程序查询（轮询）方式下，CPU 启动设备后不断读取接口的状态寄存器，检查设备是否就绪：若未就绪则继续查询，若就绪则执行一次数据传送，然后继续查询下一位/下一个数据，直到整批数据传送完毕。它的优点是硬件结构最简单、控制逻辑最少、不需要中断机构；缺点是 CPU 与设备完全串行工作，CPU 把大量时间浪费在循环查询上，效率极低，而且无法及时响应突发的外部事件。程序查询方式只适合设备速度较快、CPU 任务不重或对成本极其敏感的简单系统，在教学中它常作为理解后续中断与 DMA 方式的对照基准。

## 中断方式：响应过程与中断隐指令
中断方式让设备在就绪时主动向 CPU 发出中断请求，CPU 在一条指令执行结束后检测请求，若允许响应则暂停现行程序转去执行中断服务程序，处理完毕后返回原程序继续执行。CPU 与设备因此可以并行工作，效率远高于程序查询。中断响应过程包括：设备发出中断请求、多个请求时由中断判优电路选出优先级最高者、CPU 在当前指令执行结束后发出中断响应信号、转入中断服务程序。其中由硬件自动完成的三步称为中断隐指令（它不是一条真正的指令）：一是关中断，防止响应过程被新中断打断；二是保存断点，把当前 PC 的值（下一条指令地址）压入堆栈或存入指定单元；三是取出中断服务程序的入口地址送入 PC，从而转入服务程序。中断向量即中断服务程序的入口地址（或入口地址的指针），中断向量表按中断类型号索引存放全部向量。服务程序的一般流程是：保护现场（保存通用寄存器与 PSW）、执行中断服务、恢复现场、开中断、执行中断返回指令。

## 多重中断与中断屏蔽
多重中断（中断嵌套）指在处理某个中断的过程中允许被优先级更高的中断请求打断，从而使高优先级事件得到及时处理。实现多重中断需要两个条件：在保护完现场之后开中断（否则新中断无法被响应）；以及设置中断屏蔽字来控制哪些中断可以被响应。中断屏蔽字中每一位对应一个中断源，为 1 表示屏蔽（禁止）、为 0 表示开放；通过为不同级别的中断服务程序设置不同的屏蔽字，可以灵活地指定处理次序，甚至把某级中断的优先级调整得高于或低于硬件排队顺序。需要注意的是：中断屏蔽字只影响响应次序，不改变中断请求的产生；而未屏蔽的请求仍会保存在中断请求寄存器中，待相应中断服务程序处理到时再响应（即中断请求的"记忆"功能）。

## DMA 方式
DMA（直接存储器存取）由专门的 DMA 控制器在设备与主存之间直接传送数据块，不需 CPU 逐字干预。控制器由主存地址寄存器（每传送一次加 1）、字计数器（减到 0 时发结束信号）、数据缓冲寄存器、设备地址与控制逻辑及中断机构组成。传送过程分三步：预处理由 CPU 初始化地址、字数与方向并启动设备；传送阶段由 DMA 控制器申请并获得总线后直接完成传送；后处理阶段传完后向 CPU 发中断。DMA 与 CPU 争用总线有三种方式：停止 CPU 访存、周期挪用即周期窃取、交替访问，分别对应 DMA 独占总线、利用 CPU 空闲周期传送、存取周期分给双方各一半。DMA 与中断的区别是：中断靠 CPU 执行程序逐字传送、指令执行结束后才响应且优先级低，适合少量数据与随机事件；DMA 由硬件直接传送、机器周期结束后即可响应且优先级高，适合大批量数据块传送，结束时才用中断通知 CPU。

## 通道方式与 I/O 系统的发展
通道（I/O 处理机）是可以执行通道程序的专用处理部件，进一步把 I/O 控制从 CPU 手中解放出来：CPU 只需执行一条启动 I/O 指令，把通道程序在主存中的首地址与要访问的设备告诉通道，通道便独立地取出并执行通道指令，控制一批数据的传送，完成后用中断通知 CPU。通道指令（通道命令字）比机器指令简单，主要负责设备选择、数据传送方向与传送量控制。按连接设备的方式分为三类：字节多路通道适合连接多台慢速设备，以字节为单位在各设备间交叉传送；选择通道一次只服务一台高速设备，以成组方式连续传送整批数据；数组多路通道兼具两者特点，连接多台高速设备并以数据块为单位交叉传送。从程序查询、中断、DMA 到通道，I/O 控制的发展主线是不断把 CPU 从 I/O 事务中解放出来，让数据传输的并行度与自动化程度越来越高。

## 常见易错点与小结
常见错误包括：计算总线带宽时忘记把"位"换算成"字节"，或忽略一个总线周期包含多个时钟；把链式查询的优点说成"优先级可变"（实际优先级固定且不可改）；混淆中断隐指令与普通指令，或在中断响应过程中漏掉"关中断"这一步；把 DMA 的后处理中断与数据传送中断混为一谈；以及在多重中断中误以为屏蔽字改变的是中断请求的产生条件。本章的总线索是两条：总线的核心矛盾是"共享与争用"，解决手段是仲裁（决定谁用）与定时（决定怎么用）；I/O 的核心矛盾是"CPU 与设备速度悬殊"，解决手段从程序查询、中断、DMA 演进到通道，每一步都在进一步减少 CPU 的干预程度。
