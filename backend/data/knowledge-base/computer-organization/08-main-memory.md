# 主存储器
## 存储元与存储芯片
存储元是保存一位二进制的基本电路。RAM 分为易失的静态 SRAM（触发器）与动态 DRAM（电容需刷新）；ROM 掉电不丢失，用于固化程序。
## SRAM 与 DRAM
SRAM 速度快、无需刷新、成本高，用作 Cache；DRAM 集成度高、需周期刷新、成本低，用作主存。刷新会占用部分存储周期。
## 存储容量扩展
字扩展用译码器选择芯片以扩展地址空间；位扩展把多片同地址芯片并联以扩展数据宽度；字位同时扩展则组合两种方式。
## 地址译码
CPU 发出的地址经译码选中某芯片与芯片内单元。高位地址选择芯片，低位地址选择片内单元，译码方式有全译码与部分译码。
## 主存与 CPU 的连接
地址线、数据线、读写控制、片选信号共同完成访问。按字节编址与按字编址影响地址位数与容量计算，是组原计算题的常见陷阱。
## 典型问题
用容量小的芯片拼大主存时，先算需要芯片总数 = 总容量除以单片容量，再区分是字扩展还是位扩展；计算地址线根数由可寻址单元数取对数得到。
