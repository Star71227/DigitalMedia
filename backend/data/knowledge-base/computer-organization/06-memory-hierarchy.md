# 存储层次
## 存储层次结构
寄存器、Cache、主存、磁盘（辅存）构成自高到低的存储层次：越靠近 CPU 速度越快、容量越小、单位成本越高。层次结构用较小的高速存储器承接频繁访问，用大容量低速存储保存全部数据。
## 局部性原理
时间局部性指刚被访问的信息很快再次被访问；空间局部性指相邻信息很快被访问。存储层次利用局部性让绝大多数访问命中高层存储。
## 命中与失效率
命中率是命中高层存储的访问比例，失效率等于 1 减命中率。平均访问时间等于命中时间加失效率乘以失效开销，是衡量层次结构性能的核心指标。
## Cache 与主存
Cache 保存主存中被频繁访问块的副本。主存地址划分成标记、索引与块内偏移，用于在 Cache 中查找；Cache 与主存按块交换。
## 虚拟存储器
虚拟存储把外存空间映射为逻辑地址空间，使程序可用地址超过物理内存。它与 Cache 都利用局部性，但 Cache 解决速度、虚拟存储解决容量。
## 性能优化
提高命中率的途径有增大块、提高关联度、改进替换算法与预取。增大块利用空间局部性，但块过大可能浪费带宽并减少可缓存块数。
## 典型问题
计算平均访问时间时按“命中时间 + 失效率 × 失效开销”代入；比较两级 Cache 时注意 L2 的命中是在 L1 失效后的局部命中率。
