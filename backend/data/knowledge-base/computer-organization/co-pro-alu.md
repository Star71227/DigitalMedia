# 运算方法与运算器

## 补码加减运算
补码加减法的实现依赖两个恒等式：[x+y]补 = [x]补 + [y]补 (mod 2^n)，[x−y]补 = [x]补 + [−y]补 (mod 2^n)。求 [−y]补 的办法是把 [y]补 连同符号位一起按位取反、末位加 1。运算时把符号位当作普通数值位参与加法，最高位产生的进位直接丢弃。例如 8 位下 7 + (−5)：00000111 + 11111011 = 00000010 = +2；再如 5 − 7 = 00000101 + 11111001 = 11111110 = −2。只要不溢出，结果就是正确的补码；一旦溢出，结果的位模式虽然合法，但真值已经出错，因此必须由硬件另行检测。

## 溢出的判断：符号位判别
两个同号数相加才可能溢出：若两个正数相加得到负数，或两个负数相加得到正数，则发生了溢出。用 S_a、S_b 表示加法器两个实际输入的符号位（做减法时第二个实际输入是 [−y]补）、S_f 表示结果符号位，判溢出的逻辑表达式为 V = ¬S_a ∧ ¬S_b ∧ S_f ∨ S_a ∧ S_b ∧ ¬S_f。注意判别依据始终是两个实际输入的符号：做减法时第二个输入已被取反，因此 127 − (−1) 这类减法同样会溢出（实际是 +127 与 +1 相加）。这种方法只需看符号位，电路最简单，是理解溢出本质最直观的入口。

## 溢出的判断：双符号位
双符号位法又称变形补码法，用两位符号位表示一个数：正数用 00 表示，负数用 11 表示，数值位不变。运算时两位符号位一同参加加法，结果的双符号位固定为四种组合：00 表示结果为正且未溢出，11 表示结果为负且未溢出，01 表示发生了正溢出（上溢），10 表示发生了负溢出（下溢）。因此判溢出的表达式极其简洁：V = S_f1 ⊕ S_f2。无论结果是否溢出，最高位符号位 S_f1 始终代表正确的符号。双符号位法判溢出速度快、逻辑简单，代价是多用一位，属于"用冗余位换取判断便利"的典型做法。

## 溢出的判断：进位判别
设 C_n 为符号位相加产生的进位，C_{n−1} 为最高数值位相加产生的进位，则溢出标志 V = C_n ⊕ C_{n−1}。其原因是：若两个符号位为 0 的正数相加，数值部分产生进位会涌入符号位（C_{n−1}=1）而符号位不产生进位（C_n=0），于是符号位被写成 1，结果变成了负数，这正是正溢出；两个负数相加的情形完全对称。当两个数的符号位不同（一正一负）时，C_n 与 C_{n−1} 必然同时为 0 或同时为 1，异或结果为 0，不会误报溢出。进位判别法无须增加符号位，只需在加法器的最高两位掏出两个进位信号做异或，是实际硬件中最常用的方案。

## 移位运算
移位运算分逻辑移位、算术移位和循环移位三类。逻辑移位把操作数看成一串无符号位，左移或右移空出的位一律补 0，用于无符号数的乘除与位串操作。算术移位处理有符号数：原码移位时符号位不参加移位，只对数值位操作，左移低位补 0、右移高位补 0；补码与反码移位时符号位参加移位，补码左移低位补 0、右移高位补符号位，反码左移低位补 0、右移高位补 1。算术左移相当于乘 2，若移位前后符号位发生变化则说明溢出；算术右移相当于除以 2（向 −∞ 取整）。循环移位分不带进位与带进位两种，常用于位串的旋转与乘除法的中间步骤。

## 原码一位乘法
原码乘法的核心思想是"符号位单独处理、数值部分按绝对值相乘"。两数符号位做异或得到积的符号，数值部分用无符号乘法求出 2n 位结果，再拼上符号位。硬件上设置三个寄存器：部分积寄存器 A（取 n+1 位以容纳相加产生的进位）、乘数寄存器 Q（n 位）、被乘数寄存器 M（n 位）。每轮循环先判断 Q 的最低位：为 1 则 A ← A + M，为 0 则只移位；随后 A 与 Q 拼接后整体逻辑右移一位。如此重复 n 次，A 的低 n 位与 Q 拼接即得 2n 位乘积（A 的最高位已被移出为 0）。

```c
#include <stdint.h>

/* 无符号数一位乘法（原码数值部分的算法） */
uint32_t mul_u8(uint8_t a, uint8_t b) {
    uint16_t A = 0, M = a, Q = b;            /* A 取 9 位以容纳进位 */
    for (int i = 0; i < 8; i++) {
        if (Q & 1) A = (uint16_t)((A + M) & 0x1FF);
        uint32_t t = ((uint32_t)A << 8) | Q;  /* A 与 Q 拼接，须用 17 位 */
        t >>= 1;                              /* 整体逻辑右移一位 */
        A = (uint16_t)((t >> 8) & 0x1FF);
        Q = (uint8_t)(t & 0xFF);
    }
    return (uint32_t)(((uint32_t)A & 0xFF) << 8 | Q);
}
```

## 补码一位乘法（Booth 算法）
Booth 算法把原码乘法的"绝对值相乘"改造成直接对补码运算。设被乘数 [x]补、乘数 [y]补 各有 n 位数值位，在乘数最低位右侧增设附加位 y_{n+1}，初值为 0。每轮循环观察乘数最低位 y_n 与其右侧附加位 y_{n+1} 的组合：00 或 11 时部分积加 0；01 时部分积加 [x]补；10 时部分积加 [−x]补（[x]补 取双符号位以保证中间结果不溢出）。加完后，把部分积与乘数（含附加位）作为一个整体算术右移一位。执行 n 轮后，部分积与乘数寄存器拼接起来就是 2n 位乘积的补码。Booth 算法的本质是用差值 y_{n+1} − y_n 决定加减，从而自动处理符号位，还能跳过连续相同的乘数位。

## 原码除法：恢复余数法
原码除法同样把符号与数值分开处理：商的符号由被除数与除数的符号位异或得到，数值部分用两个绝对值相除。恢复余数法先用被除数（或余数）减除数，若余数为正说明够减，商上 1；若余数为负说明不够减，商上 0，并必须把除数加回余数（称"恢复余数"），恢复之后再继续。随后把余数与被除数剩余部分一起左移一位，进入下一轮，共进行 n 轮得到 n 位商。该方法的缺点很突出：每次上商为 0 都要多做一次加法来恢复余数，导致运算步数不固定、控制时序复杂、平均速度慢。

## 原码除法：加减交替法
加减交替法（不恢复余数法）消除了恢复余数这一步。其依据是：当余数为负时，恢复余数得到 R + Y，再左移得 2(R + Y)，下一步本应做 2(R + Y) − Y；而若直接保留负余数左移再减 Y，得到 2R − Y，两者相差 2Y，因此只需把"减 Y"改为"加 Y"即可得到同样的结果。于是规则变为：余数为正时上商 1，下一步做左移后减除数；余数为负时上商 0，下一步做左移后加除数。这样每轮固定只做一次加法或减法，步数确定，控制简单，硬件利用率高，是原码除法的标准实现方式。

## 补码除法与商的处理
补码除法直接把参加运算的数表示为补码，符号位参与运算，商符在运算过程中自然形成。基本规则是：被除数与除数同号时第一步做减法（相当于减去异号的除数），异号时第一步做加法；每一步根据当前余数与除数是否同号来决定商位是 1 还是 0，然后余数左移一位并按同样规则继续。由于补码除法得到的商可能比真值偏小，末位通常需要修正，常用"末位恒置 1"法或专门的校正法。补码除法省去了符号位的单独处理，但逻辑比原码除法复杂，是低层硬件实现的常见选择。

## 串行进位加法器
n 位串行进位加法器（行波进位加法器）由 n 个一位全加器级联而成：第 i 位的全加器接收本位的两个加数位 A_i、B_i 以及来自低位的进位 C_i，输出本位和 S_i 与向高位的进位 C_{i+1} = A_i B_i + (A_i ⊕ B_i) C_i。由于进位必须逐级传递，最高位要等低位进位稳定后才能算出，总延迟与位数 n 成正比（约为 2n 级门延迟）。串行进位加法器结构最简单、占用面积最小，但速度随位数线性下降，只适合位数很少或对速度不敏感的场合。

## 先行进位加法器
先行进位（超前进位）加法器从进位公式出发，定义进位生成函数 G_i = A_i B_i 与进位传递函数 P_i = A_i ⊕ B_i，于是 C_{i+1} = G_i + P_i C_i。逐层展开可得到只依赖 A、B 各值与最低位进位 C_0 的表达式，例如 C_1 = G_0 + P_0 C_0，C_2 = G_1 + P_1 G_0 + P_1 P_0 C_0。这样所有进位都能并行产生，延迟基本与位数无关。代价是门电路的扇入迅速增大，位数一多就无法用单级逻辑实现，因此实用方案是分组先行进位：先用 4 位先行进位部件构成 4 位加法器，再用专门的先行进位部件（如 74182）把这些部件的进位串起来，组成 16 位、32 位乃至 64 位加法器，兼顾速度与扇入限制。

## ALU 的功能与结构
算术逻辑单元（ALU）是运算器的核心，能完成加、减、与、或、非、异或等算术与逻辑运算。它的输入是两路操作数 A、B 和一组功能选择信号，输出为运算结果 F 以及若干状态标志位。典型的 4 位 ALU 芯片 74181 用 4 位功能选择码 S3~S0 与一位方式控制信号 M 来选择功能：M=1 时执行 16 种逻辑运算，M=0 时执行 16 种算术运算，同时输出进位产生/传递信号以便与先行进位部件级联。ALU 本身不含寄存器，它的操作数来自通用寄存器、暂存器或移位器的输出，结果写回寄存器或送往标志电路。

## 状态标志
运算结果的特征用状态标志表示，通常放在程序状态字寄存器（PSW）中，供条件转移指令与程序判断使用。常用标志有：ZF 零标志（结果为 0 时置 1）、SF 符号标志（结果最高位，表示正负）、OF 溢出标志（有符号数溢出时置 1，由进位判别或双符号位判别得到）、CF 进位/借位标志（无符号数运算的最高位进位或借位）、PF 奇偶标志（结果中 1 的个数为偶数时置 1）。需要特别区分 OF 与 CF：OF 服务于有符号数，CF 服务于无符号数，同一次加法可能 CF=1 而 OF=0，也可能反之。

```c
#include <stdint.h>

/* 演示 OF 与 CF 的区别：同一次加法在有符号与无符号视角下的结果 */
void demo_flags(void) {
    int8_t  s1 = 100, s2 = 100;
    uint8_t u1 = 100, u2 = 100;
    int8_t  s = (int8_t)(s1 + s2);    /* 有符号值 200 超出 int8_t 范围 */
    uint8_t u = (uint8_t)(u1 + u2);   /* 无符号值 200 在 uint8_t 范围内 */
    /* 汇编中：s 的加法使 OF=1、CF=0；u 的加法使 CF=0、OF=0 */
    (void)s; (void)u;
}
```

## 运算器的组成
运算器由算术逻辑单元、通用寄存器组、暂存器、移位电路、标志寄存器以及连接这些部件的内部总线组成。通用寄存器为程序员可见，用于存放操作数与中间结果；暂存器对程序员透明，用于暂存从主存读出或总线送来的数据，避免破坏通用寄存器的原值；移位电路实现算术、逻辑与循环移位；标志寄存器保存运算状态。按内部总线数量，运算器可分为单总线结构（一次只能送一个数据，一条运算需多个节拍完成）、双总线与三总线结构（可同时送出两个操作数，速度快但硬件多）。

## 乘除法运算器与阵列乘法器
高速机器中乘除法常用专门的硬件实现。阵列乘法器由 n×n 个全加器构成的乘加单元阵列组成，所有部分积并行产生并逐层相加，延迟只与阵列层数成正比，速度远高于"移位加"的迭代方案，代价是芯片面积随 n² 增长。除法可用阵列除法器或迭代的加减交替电路实现。许多现代处理器把乘法、除法、浮点运算做成独立的功能部件，与整数加减并行工作，并由流水线化的乘加单元支持每个周期启动一次新运算。

## 常见易错点与小结
本章易错点集中在四个方面：一是把"进位丢失"当作溢出，忽略有符号与无符号溢出的不同判据；二是混淆原码与补码的算术移位规则，忘记补码右移补的是符号位、原码符号位不参与移位；三是在 Booth 算法中遗漏附加位或忘记对部分积取双符号位；四是在除法中把上商规则与余数符号对应关系弄反。运算方法的总线索是"用加法器加移位器实现一切"：减法转成补码加法，乘法转成加与右移的迭代，除法转成减（或加）与左移的迭代，位移就是把乘 2、除 2 变成一次移位操作。
