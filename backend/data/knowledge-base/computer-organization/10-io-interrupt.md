# I/O与中断
## I/O 接口
I/O 接口在 CPU 与设备间完成数据缓冲、格式转换、状态报告与地址译码。接口中的数据寄存器、状态寄存器与控制寄存器通过端口编址访问。
## 程序查询方式
CPU 不断读取设备状态，设备就绪才传送数据。实现简单但 CPU 在等待期间不能做其他事，效率低，适合低速且简单的场合。
## 程序中断方式
设备就绪时向 CPU 发出中断请求，CPU 响应后保存现场、转入中断服务程序，完成后恢复现场返回。CPU 与设备可并行工作，提高系统吞吐。
## 中断向量
每个中断源有对应的中断向量，指向中断服务程序入口。中断隐指令完成关中断、保护断点、取中断向量；中断响应需判优、屏蔽与现场保护。
## DMA 方式
DMA 控制器接管总线，在主存与设备之间直接传送数据，CPU 仅在开始与结束时介入。DMA 传送结束时通过中断通知 CPU，适合高速批量数据。
## 通道方式
通道是能执行通道程序的专用处理器，进一步分担 CPU 的 I/O 管理。通道与 DMA 的区别在于通道可自主执行指令序列，处理更复杂的 I/O 流程。
## 典型问题
比较三种方式看 CPU 参与程度：程序查询全程参与、中断方式仅在传送与处理时介入、DMA 只在传送开始和结束介入。计算传输效率时按实际传送时间与总时间之比。
