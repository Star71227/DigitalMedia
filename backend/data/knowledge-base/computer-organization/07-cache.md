# 高速缓冲存储器
## Cache 的映射方式
直接映射把主存块固定映射到唯一 Cache 行，硬件简单但冲突多；全相联可映射到任意行，命中率高但比较电路复杂；组相联折中，每块映射到一组内任意行。
## 直接映射
主存地址分为标记、行号、块内偏移。同一行号的不同主存块互相冲突，循环访问间隔为 Cache 行数的数据可能反复失效。
## 组相联映射
Cache 分成若干组，每组包含若干行，主存块映射到固定组内的任意一行。组数越多越接近全相联。它是实际处理器最常用的折中方案。
## 替换算法
直接映射无需替换；组相联与全相联常用 LRU、随机或 FIFO。LRU 命中率较高但需记录访问次序；随机实现简单且接近 LRU 的效果。
## 写策略
写直达每次写都同时更新 Cache 与主存，简单但写带宽大；写回只在替换时写回被修改块，减少主存写但需脏位。写不命中时可用写分配或写不分配策略。
## 命中率与性能
命中率受容量、块大小、关联度与替换算法影响。平均访问时间 = 命中时间 + 失效率 × 失效开销，多级 Cache 逐级累加。
## 典型问题
计算直接映射的字段位数：块内偏移由块大小决定，行号由 Cache 行数决定，标记为地址余下位数。组相联的组号由组数决定，标记比较仅在该组内进行。
