# 绪论与算法分析

## 数据结构的基本概念
数据是信息的载体，是能被计算机程序识别和处理的符号集合。数据元素是数据的基本单位，一个数据元素可由若干数据项组成，数据项是不可分割的最小单位。数据对象是具有相同性质的数据元素的集合。

## 数据结构三要素
数据结构包括逻辑结构、存储结构和数据的运算。逻辑结构描述元素间的逻辑关系，分集合、线性结构、树形结构、图状结构四类。存储结构（物理结构）是逻辑结构在计算机中的表示，包括顺序存储、链式存储、索引存储和散列存储。数据的运算定义在逻辑结构上，具体实现依赖存储结构。

## 顺序存储与链式存储的比较
顺序存储用连续单元依次存放，逻辑相邻则物理相邻，支持随机访问但插入删除需移动元素。链式存储靠指针表示逻辑关系，不要求物理相邻，插入删除不需移动元素但只能顺序访问，且需要额外指针空间。

## 算法的定义与特性
算法是对特定问题求解步骤的描述，具有五个特性：有穷性（有限步内结束）、确定性（相同输入得到相同输出）、可行性（每步都能有效执行）、输入（零个或多个）、输出（一个或多个）。程序可以不满足有穷性，算法必须满足。

## 时间复杂度
时间复杂度是算法基本操作执行次数随问题规模 n 增长的渐近趋势，记作 T(n)=O(f(n))。分析时只保留最高阶项并去掉常数系数。常见量级由小到大：O(1)、O(log n)、O(√n)、O(n)、O(n log n)、O(n²)、O(n³)、O(2ⁿ)、O(n!)。

## 渐近记号
O 表示渐近上界，Ω 表示渐近下界，Θ 表示紧确界。O(n) 只说明增长速度不超过 n 的常数倍，不排除算法实际是 O(1)。使用记号时必须说明问题规模的含义。

## 复杂度分析实例
```c
// O(1)：与 n 无关
int first(int a[]) { return a[0]; }

// O(log n)：i 每次翻倍
int countLog(int n) { int c = 0; for (int i = 1; i <= n; i *= 2) c++; return c; }

// O(n)：单层循环
int sum(int a[], int n) { int s = 0; for (int i = 0; i < n; i++) s += a[i]; return s; }

// O(n log n)：外层 log n，内层 n
int nlogn(int n) { int c = 0; for (int i = 1; i <= n; i *= 2) for (int j = 0; j < n; j++) c++; return c; }

// O(n²)：双层循环
int n2(int n) { int c = 0; for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) c++; return c; }
```

## 最好、最坏、平均与摊还
最好情况是最有利输入下的代价，最坏情况是最不利输入下的上界，平均情况按输入分布加权。工程上更关注最坏情况，因为它给出确定保证。摊还分析把一串操作的总代价分摊到单次操作，例如动态数组扩容使单次插入的摊还代价为 O(1)。

## 空间复杂度
空间复杂度统计算法所需的额外辅助空间随 n 的增长趋势，不含输入本身。原地算法只使用 O(1) 额外空间；递归算法需计入调用栈深度，例如递归深度为 n 的算法空间复杂度为 O(n)。

## 递归的复杂度分析
递归算法列出递推式后求解。归并排序 T(n)=2T(n/2)+O(n) 解得 Θ(n log n)；二分查找 T(n)=T(n/2)+O(1) 解得 Θ(log n)；朴素斐波那契 T(n)=T(n-1)+T(n-2) 为指数级。主定理：对 T(n)=aT(n/b)+f(n)，比较 f(n) 与 n^(log_b a) 的量级即可确定结果。

## 常见易错点
只看循环层数判断复杂度容易出错，i *= 2 的单层循环是 O(log n)，而 i*i <= n 的循环是 O(√n)。忽略输入规模的定义会导致结论无意义。此外，渐近复杂度相同不代表实际性能相同，常数因子、缓存局部性和数据分布都会影响实测结果。

## 本节小结
本章建立了后续所有内容的基础：数据的逻辑结构与存储结构决定操作代价，算法分析用渐近记号刻画增长趋势，复杂度分析是评价与选择数据结构的核心依据。
