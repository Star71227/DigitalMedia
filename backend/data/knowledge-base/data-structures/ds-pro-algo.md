# 算法设计思想与并查集

## 分治法
分治法的思想是把一个规模为 n 的问题分解为 k 个规模较小的子问题，这些子问题相互独立且与原问题形式相同，递归求解后再把子问题的解合并得到原问题的解。三个步骤：分解、解决、合并。适用条件是子问题相互独立（不重叠）、且合并代价可接受。

## 分治法的典型应用
二分查找（T(n)=T(n/2)+O(1)，O(log n)）、归并排序（T(n)=2T(n/2)+O(n)，O(n log n)）、快速排序（平均 O(n log n)）、求最大最小元素、大整数乘法、棋盘覆盖、循环赛日程表。分治法的复杂度分析通常用主定理或递归树。

## 动态规划
动态规划适用于具有**最优子结构**和**重叠子问题**的问题。它把问题分解为相互重叠的子问题，保存子问题的解避免重复计算。实现方式有自顶向下的记忆化搜索和自底向上的递推填表。关键步骤：定义状态、写出状态转移方程、确定边界条件与计算顺序。

## 动态规划的典型问题
0-1 背包（每个物品选或不选）、完全背包（物品可重复选）、最长公共子序列 LCS、最长递增子序列 LIS、编辑距离、矩阵连乘（区间 DP）、最短路径中的 Floyd 算法、最优二叉搜索树。区分动态规划与分治：分治的子问题互不重叠，动态规划的子问题重叠。

## 贪心算法
贪心算法在每一步都做出当前看来最优的选择，并期望通过局部最优达到全局最优。贪心不保证得到最优解，只有当问题具有**贪心选择性质**（局部最优可导向全局最优）和**最优子结构**时才能得到正确结果。

## 贪心的典型应用与正确性
活动安排问题（按结束时间排序，选结束最早的）、区间调度、哈夫曼编码（每次合并权值最小的两棵树）、最小生成树的 Prim 与 Kruskal、单源最短路径的 Dijkstra、部分背包问题（按单位价值排序）。反例：0-1 背包不能直接用贪心（按单位价值排序会得到次优解），必须用动态规划。

## 回溯法
回溯法在问题的解空间树中按深度优先策略搜索，到达某结点时先判断该结点是否可能包含可行解，若不可能则剪枝并回溯。适用于求解组合数较大但可以用约束条件剪枝的问题。典型应用：八皇后、迷宫求解、图的着色、子集和、旅行商问题、数独。回溯法本质是带剪枝的穷举，最坏复杂度仍是指数级。

## 分支限界法与回溯法的区别
回溯法用深度优先搜索解空间树，目标是找出所有（或任一）满足约束的解；分支限界法用广度优先或最小耗费优先搜索，通常借助优先队列，目标是在满足约束的解中找最优解，并通过限界函数剪掉不可能更优的分支。

## 并查集
并查集是维护不相交集合的数据结构，支持两个操作：Find(x) 查找元素所在集合的代表元；Union(x, y) 把两个集合合并。用树的双亲表示实现：parent[i] 记录 i 的父结点，根结点的 parent 指向自己。

## 并查集的优化
- 路径压缩：Find 时把查找路径上的所有结点直接连到根，使后续查找近似 O(1)。
- 按秩合并（按大小合并）：Union 时把结点数少或高度小的树接到大的树上，避免树退化。
同时使用两种优化后，单次操作的摊还复杂度为 O(α(n))，其中 α 是反阿克曼函数，在实际规模下不超过 5，可视为常数。

## 完整代码：并查集
```c
#include <stdio.h>
#define MAXN 100000

int parent[MAXN];
int rank_[MAXN];                       // 秩：树高的上界

void Init(int n) {                     // 初始化：每个元素自成一个集合
    for (int i = 0; i <= n; i++) { parent[i] = i; rank_[i] = 0; }
}

int Find(int x) {                      // 路径压缩
    if (parent[x] != x) parent[x] = Find(parent[x]);
    return parent[x];
}

void Union(int x, int y) {             // 按秩合并
    int rx = Find(x), ry = Find(y);
    if (rx == ry) return;
    if (rank_[rx] < rank_[ry]) parent[rx] = ry;
    else if (rank_[rx] > rank_[ry]) parent[ry] = rx;
    else { parent[ry] = rx; rank_[rx]++; }
}

int Connected(int x, int y) { return Find(x) == Find(y); }
```

## 并查集的典型应用
判断无向图的连通性、统计连通分量个数、Kruskal 最小生成树中判断成环、等价类划分、社交网络中的朋友关系合并、动态连通性问题。并查集不支持删除操作（"分裂"需要可持久化或离线逆序处理）。

## 常见易错点
Find 忘记路径压缩会导致树退化、复杂度上升。Union 时忘记先 Find，直接把两个元素相连会连错根。把并查集与堆混淆（一个解决分组，一个解决极值）。误认为贪心一定能得到最优解——不具备贪心选择性质时必须改用动态规划。动态规划时状态定义不完整或计算顺序错误导致使用了尚未求出的子问题。

## 本节小结
四大算法设计思想各有适用条件：分治要求子问题独立，动态规划要求子问题重叠，贪心要求局部最优可导向全局最优，回溯用于带约束的组合搜索。并查集是解决动态连通性问题的专用结构，配合路径压缩与按秩合并后接近常数时间，在最小生成树、连通性判定等场景中不可替代。
