# 堆与优先队列

## 堆的定义
堆（Heap）是满足堆序性质的完全二叉树。大根堆中每个结点的关键字都不小于其孩子，堆顶是最大值；小根堆中每个结点的关键字都不大于其孩子，堆顶是最小值。堆序只约束父子关系，不约束兄弟关系，因此堆不是有序结构。

## 堆的顺序存储
由于堆是完全二叉树，可以直接用数组按层序存储，无需指针。从下标 1 开始时，结点 i 的父结点为 ⌊i/2⌋，左孩子为 2i，右孩子为 2i+1。从下标 0 开始时，父结点为 ⌊(i−1)/2⌋，左孩子为 2i+1，右孩子为 2i+2。

## 上浮与下沉
上浮（sift up）：在堆尾插入新元素后，若它比父结点更优先则与父结点交换，重复直到满足堆序。下沉（sift down）：把根替换为堆尾元素后，与更优先的孩子交换，重复直到满足堆序。两种操作的时间复杂度都是 O(log n)，即树高。

## 建堆
自底向上建堆：从最后一个非叶结点（下标 ⌊n/2⌋）开始，依次对每个结点执行下沉，直到根。时间复杂度为 O(n)，而非 O(n log n)——这是因为大部分结点位于底层，下沉距离很短，可证明总代价为线性。逐个插入建堆则需要 O(n log n)。

## 插入与删除堆顶
插入：把新元素放在堆尾，然后上浮，O(log n)。删除堆顶：把堆尾元素移到堆顶，堆长度减一，然后对新堆顶下沉，O(log n)。取堆顶元素 O(1)。

## 完整代码：小根堆
```c
#define MAXN 100000
int heap[MAXN + 1], n = 0;          // 下标从 1 开始，n 为元素个数

void SiftUp(int i) {
    while (i > 1 && heap[i] < heap[i / 2]) {
        int t = heap[i]; heap[i] = heap[i / 2]; heap[i / 2] = t;
        i /= 2;
    }
}

void SiftDown(int i) {
    while (2 * i <= n) {
        int j = 2 * i;                                    // 左孩子
        if (j + 1 <= n && heap[j + 1] < heap[j]) j++;     // 选更小的孩子
        if (heap[i] <= heap[j]) break;
        int t = heap[i]; heap[i] = heap[j]; heap[j] = t;
        i = j;
    }
}

void Push(int x) { heap[++n] = x; SiftUp(n); }
int Top(void) { return heap[1]; }
void Pop(void) { heap[1] = heap[n--]; SiftDown(1); }

void BuildHeap(int a[], int len) {     // O(n) 建堆
    n = len;
    for (int i = 1; i <= len; i++) heap[i] = a[i - 1];
    for (int i = n / 2; i >= 1; i--) SiftDown(i);
}
```

## 堆排序
堆排序分两步：先用 O(n) 时间建大根堆；然后重复 n−1 次"把堆顶与当前堆尾交换、堆长度减一、对新堆顶下沉"，每次把当前最大值放到最终位置。总时间复杂度 O(n log n)，空间复杂度 O(1)（原地排序），是不稳定排序。堆排序适合需要同时取得前 k 大元素且空间受限的场景。

## 优先队列
优先队列是每次取出优先级最高元素的抽象数据类型，堆是其最常用的实现。优先队列支持插入、取最值、删除最值，均可在 O(log n) 内完成。应用包括任务调度、事件驱动模拟、Dijkstra 与 Prim 的堆优化、Top-K 问题。

## Top-K 问题
求 n 个元素中最大的 k 个：维护一个大小为 k 的小根堆，遍历元素时若大于堆顶则替换堆顶并下沉。时间复杂度 O(n log k)，空间 O(k)。相比全排序 O(n log n) 更优，尤其在 n 很大、k 很小时。

## 对顶堆求中位数
维护一个大根堆存较小的一半元素、一个小根堆存较大的一半元素，并保持两堆大小差不超过 1。插入 O(log n)，取中位数 O(1)。这是数据流中位数问题的标准解法。

## 可并堆
当需要合并两个堆时，二叉堆的合并代价为 O(n)。可并堆支持高效合并：左偏树通过维护每个结点的"零路径长度"保证左偏性质，合并复杂度 O(log n)；配对堆实现简单、均摊性能好；斐波那契堆理论最优但常数大、实现复杂。

## 常见易错点
下标从 0 还是从 1 开始未统一，导致父子下标算错。把建堆复杂度误记为 O(n log n)（自底向上是 O(n)）。删除堆顶时忘记先把堆尾移到堆顶再下沉。小根堆与大根堆的比较方向写反。堆排序是不稳定排序，不能用于要求稳定的场景。

## 本节小结
堆用完全二叉树的隐式数组结构实现了高效的极值访问，插入与删除均为 O(log n)，建堆为 O(n)。它是优先队列的标准实现，也是堆排序、Top-K、Dijkstra 优化等算法的基础。理解上浮与下沉两个原语，就掌握了堆的全部操作。
