# 网际协议与子网
## IP 地址
IPv4 地址是 32 位，常写成点分十进制。它由网络号和主机号组成，网络号标识网络，主机号标识网络内的主机。IP 地址是逻辑地址，可随网络规划改变。
## 分类编址
A、B、C 类地址分别用 8、16、24 位固定网络号，D 类组播、E 类保留。分类编址简单但地址浪费严重，已逐步被无分类编址取代。
## 子网掩码与子网划分
子网掩码用连续的 1 表示网络位。从主机号借用若干位作子网号，可把一个网络划分成多个子网。主机号全 0 是网络地址，全 1 是广播地址，不可分配给主机。
## 无分类编址 CIDR
CIDR 用“IP/前缀长度”表示地址块，如 192.168.1.0/24，前缀可变，支持路由聚合，减少路由表规模。
## IP 数据报
数据报首部含版本、首部长度、总长度、标识、标志、片偏移、生存时间 TTL、协议、首部校验和、源与目的地址。TTL 每经过一跳减一，防止分组在网络中无限循环。
## 分片与重组
分组超过链路 MTU 时在源或中间路由器分片，到达目的主机再重组。片偏移以 8 字节为单位，标识与标志字段用于区分和标记分片。
## 典型问题
子网划分题先确定需借的位数，计算子网数、每子网主机数与可用主机数；地址聚合题取各地址块最长公共前缀。注意网络地址与广播地址不能用于主机。
