# 数据链路层
## 数据链路层的作用
数据链路层在相邻结点间把网络层数据报封装成帧，实现透明传输、差错检测与介质访问控制。它解决点到点链路上的可靠交付与共享介质争用问题。
## 成帧
把比特流划分成帧需标识帧边界，方法有字符计数、字符填充、比特填充与物理层编码违例。帧结构含首部、数据与尾部（如校验字段）。
## 差错检测
奇偶校验简单但检错能力弱；循环冗余校验 CRC 把数据看作多项式，用生成多项式求余数作为校验值，能检测多位与突发差错，广泛用于以太网。
## 流量与可靠传输
停止等待协议每发一帧等待确认，效率低；滑动窗口协议允许连续发送多个帧，用序号与累计确认实现可靠交付并提升信道利用率。
## 以太网与 CSMA/CD
以太网采用共享介质与 CSMA/CD：发送前监听，边发边检测冲突，冲突后随机退避重传。全双工交换式以太网不再需要 CSMA/CD。
## MAC 地址
MAC 地址是 48 位链路层地址，全球唯一，用于同一网段内帧的寻址。帧首部含目的与源 MAC 地址，交换机按 MAC 地址学习并转发。
## 典型问题
计算 CRC 或判断校验时按二进制模二除法进行；计算滑动窗口或传播时延时，注意往返时间与带宽时延积，窗口序号位数必须足够避免序号混淆。
