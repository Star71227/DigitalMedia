# TCP可靠传输
## TCP 的特点
TCP 是面向连接、可靠、面向字节流的传输协议，提供全双工通信。它通过序号、确认、重传、流量控制与拥塞控制保证数据按序、无差错、不丢失地交付。
## 序号与确认
TCP 对字节流按字节编号，首部序号是本报文段第一个数据字节的序号，确认号是期望收到的下一个字节序号。累计确认表示该序号之前的数据都已收到。
## 超时重传
发送方为每个报文段设置重传定时器，超时未收到确认则重传。重传时间由往返时间 RTT 动态估计，过小导致不必要重传，过大降低恢复速度。
## 快速重传
收到三个重复确认说明其后报文可能丢失，发送方不等超时立即重传该报文，称为快速重传，能明显加快丢包恢复。
## 滑动窗口与流量控制
接收方通过窗口字段通告可用接收缓冲区大小，发送方据此控制发送量，避免淹没接收方。窗口为零时发送方暂停并等待窗口更新通知。
## 校验和
TCP 校验和覆盖伪首部与整个报文段，伪首部包含源目的 IP 与协议号，用于检测传输中的差错。校验失败的数据被丢弃。
## 典型问题
计算序号与确认号时注意：确认号是已收字节数加一；重传题判断是超时重传还是快速重传，看是否有三个重复 ACK。滑动窗口题按“已发送未确认 + 可继续发送”划分窗口。
