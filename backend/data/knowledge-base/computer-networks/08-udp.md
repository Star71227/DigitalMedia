# 用户数据报协议
## UDP 的特点
UDP 是无连接、不可靠、面向报文的传输协议，不建立连接、不保证交付、不保证顺序，但开销小、延迟低、实现简单。
## UDP 首部
UDP 首部只有源端口、目的端口、长度与校验和四个字段，共 8 字节，远小于 TCP 首部，因此头部开销低。
## UDP 的适用场景
UDP 适合对实时性要求高、允许少量丢包的场景，如音视频流、在线游戏、DNS 查询与广播组播。应用层可自行实现所需的可靠性。
## UDP 校验和
UDP 校验和覆盖伪首部与整个数据报，可选但实际常启用。校验和出错的数据报被丢弃，不做重传。
## 与 TCP 的比较
TCP 面向连接、可靠、面向字节流、有拥塞控制；UDP 无连接、不可靠、面向报文、无拥塞控制。选择协议要在可靠性与开销延迟之间权衡。
## 典型问题
判断协议选择时看应用对丢包与延迟的容忍度；计算 UDP 报文总长度时把首部 8 字节与数据长度相加，注意与 IP 数据报长度的换算。
