# 寻笺 LearnMate

> 面向计算机专业课程的多智能体个性化学习资源生成平台

寻笺 LearnMate 面向高校计算机专业课程，把**学习画像、测验与编程判题证据、动态学习路径、五类学习资源、知识检索与引用、学习评估和教师分析**串成一条可追溯的闭环：学生端完成「诊断 → 生成 → 练习 → 复盘」，教师端完成「班级学情 → 作业与题库 → 评估报告」。

平台由学生端、教师端与 Windows 桌面版三个形态组成，三端共用同一套后端与数据模型。

## 三、主要功能

**学生端**

- **七维学习画像**：专业年级、当前课程、已有基础、学习目标、讲解偏好、资源偏好、节奏与时间预算，带证据、置信度与版本历史。
- **个性化学习路径**：按知识点前置关系编排阶段，支持重新规划与版本对照，与资源、测验、错题联动。
- **五类个性化资源**：学习讲义、思维导图、教学课件、练习包、代码案例，均含结构校验、审核、版本与完成证据。
- **CodeLab 在线判题**：C 语言编译与多用例执行，结果自动回写错题与掌握度。
- **知识图谱与知识检索**：课程知识图谱可视化，检索结果绑定引用与来源快照。
- **错题本与滚动复习**：错误模式分析、掌握度热力图、复习队列。
- **学习评估报告**：基于真实作答与资源完成证据生成。
- **数字讲师**：原创 2D 形象，支持浏览器语音、音频驱动的口型与文字降级。

**教师端**

- 班级学情总览、学生学习档案、作业布置与批改、题库管理与审计、测验分析、智能体运行日志、版本化 PDF 学习报告。

**平台能力**

- **多智能体协同**：画像、资源、审核、规划、组卷、反馈、助教、评估八类智能体围绕统一学生状态协作，关键链路带确定性回退。
- **可解释生成**：异步任务持久化后端阶段，实时推送进度与审核事件，刷新或断线不会重复生成。
- **课堂演示通道**：可切换为预置样例秒出（课件与导图直接装配、讲义复用已有版本），避免现场等待模型生成。

## 四、技术栈

| 层 | 选型 |
| --- | --- |
| 学生端 / 教师端 | React 19 + TypeScript + Vite，Tailwind CSS，Recharts、GSAP |
| 后端 | Node.js 24 + Express + MySQL 8.4 |
| 课件生成 | PptxGenJS + JSZip |
| 大模型 | **用智谱 GLM**（`bigmodel`），|
| 代码判题 | Docker 判题镜像（服务器）或随包便携 C 编译器（桌面版） |
| 部署 | Docker Compose + Nginx；桌面版为 Electron 外壳 + 内置运行环境 |
