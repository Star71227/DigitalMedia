# 学生端组卷与在线判题修复

## 联网组卷

原故障：百度页面结构变化或返回空页时直接抛出 503，整个组卷请求中断；C 语言名称的空格也导致相关性筛选漏掉结果。

现在并行尝试两个公开搜索源，修正 C 语言关键词匹配。两者不可用时，从课程题库补足题目，结果明确说明未使用联网资料。模型选题限制为 20 秒，失败时按薄弱点、学习路径和难度排序；降级结果不标为 AI 选题。题目不由搜索摘要临时改写。

本机真实验证：C 语言 5/5 题约 4.5 秒，20/20 题约 8.2 秒，均返回 6 个联网资料来源并完成模型选题。时间受网络和模型负载影响。

## CodeLab

- 自定义运行：使用学生填写的标准输入，支持空输入，显示标准输出和错误，不计为题目 AC。
- 运行样例：使用题目的公开样例并比较输出。
- 提交评测：运行题目配置的公开、隐藏用例；显示 AC / WA / CE / RE / TLE / OLE、耗时和测试点状态，隐藏输入和答案不下发。
- 遇到失败测试点后停止，剩余测试点明确显示未执行。
- 编译运行在无网络、只读文件系统、非 root 用户的 Docker 容器中进行，限制内存、CPU、进程、输出大小及运行时间。
- 支持 C11，与现有 C 语言练习库一致。

## 本机启用

根目录运行 `启用CodeLab在线判题.bat`。脚本使用已有 Ubuntu-24.04 WSL，按 Docker 官方 Ubuntu apt 仓库安装 Docker Engine（若已安装则复用），构建本项目判题镜像，执行真实编译、输入、WA、CE、RE、TLE、OLE 自检。只有自检全部通过才更新 `.env` 和 `backend/.env` 并重启网站。

安装依据：https://docs.docker.com/engine/install/ubuntu/

首次安装需要网络；后续启动网站会启动已经配置好的 Docker 服务。可以通过学生登录后的 `/api/code/health` 检查是否就绪。

本次执行环境调用 WSL 返回 `E_ACCESSDENIED`，因此没有实际完成安装、容器编译运行或修改 disabled 配置。当前通过的是后端单元及数据库/API 集成测试、前端类型检查和脚本语法检查；容器自检必须由上述脚本在本机成功执行，不能以模拟测试代替。
