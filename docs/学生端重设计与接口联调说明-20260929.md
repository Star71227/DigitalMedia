# 学生端重设计与接口联调说明（2026-09-29）

## 本轮范围

- 保留现有白、蓝、青配色，重做侧栏收束/展开、图标悬浮、分页面字体和背景融合。
- 首页移除“个性化闭环”说明，改成学习资料、今日学习、检测次数和编程实战四项基本信息。
- 路径页保留黑白静态鸟群，使用 SVG 引导点线和 CSS 轻微浮动；主阶段以折页进入，展开后联动导图、讲义、助手、知识检测、编程实战和报告。
- AI 学习助手使用手部静态美术素材，聊天区、图标轨道与输入框重新布局。
- “章节检测”和 CodeLab 合并为侧栏单一条目“能力检测”；知识检测与编程实战共享同一页面外壳，CodeLab 题库、编辑、运行和提交保留原功能。
- 学习报告支持近 7 天 / 近 30 天切换，折线保留直线段并增加光晕、渐变和发光节点。
- 班级排名新增真实接口，页面使用带远近虚实的神圣科技棋局静态背景和金属质感前三名徽章。
- 本轮不修改知识图谱内部网络，也不修改设置页业务内容。

## 前端接口映射

| 页面/功能 | 方法与地址 | 前端用途 |
| --- | --- | --- |
| 学习首页 | `GET /api/student/overview` | 学生、课程、测验、资源、CodeLab 汇总 |
| 学习首页 | `GET /api/study-time?days=7` | 今日学习时长 |
| 学习首页 | `GET /api/check-in/status` | 连续学习天数 |
| 学习路径 | `GET /api/path/me` | 当前路径、阶段、完成状态与进度 |
| 学习路径 | `POST /api/path/generate` | 重新生成或调整路径 |
| AI 学习助手 | `POST /api/chat/sessions` | 建立学生会话 |
| AI 学习助手 | `POST /api/chat` | 发送问题并取得回答与引用 |
| 能力检测 | `POST /api/quiz/personalized/generate` | 生成知识检测题目 |
| 能力检测 | `POST /api/quiz-hint` | 获取当前题提示 |
| 能力检测 | `POST /api/quiz/submit` | 提交检测并返回分数、掌握度变化和建议 |
| 编程实战 | `GET /api/code/exercises` | 按课程、知识点、难度读取练习 |
| 编程实战 | `POST /api/code/run` | 运行公开样例或自定义输入 |
| 编程实战 | `POST /api/code/submit` | 正式提交评测 |
| 编程实战 | `POST /api/code/explain` | 整理运行结果与改进提示 |
| 学习报告 | `GET /api/student/assessment` | 掌握度、薄弱项、风险和建议 |
| 学习报告 | `GET /api/study-time?days=7|30` | 折线图周期数据 |
| 班级排名 | `GET /api/student/class-ranking` | 班级、个人名次和排名列表 |

所有学生端接口继续使用现有登录令牌；前端不保存模型密钥，也不直接请求模型服务。

## 班级排名响应

```json
{
  "className": "数据结构 2 班",
  "updatedAt": "2026-09-29T06:00:00.000Z",
  "myRank": 3,
  "total": 36,
  "items": [
    {
      "studentId": "12",
      "name": "张三",
      "score": 4680,
      "studyMinutes": 690,
      "pathProgress": 88,
      "mastery": 89,
      "streak": 7,
      "weeklyChange": null,
      "isCurrent": true
    }
  ]
}
```

接口由 `backend/src/services/studentRankingService.js` 汇总班级成员、测验、近七天专注时长、当前路径的实时完成进度、CodeLab 提交和签到记录。没有加入有效班级时返回空列表，不伪造其他学生数据。尚未保存历史榜单时 `weeklyChange` 返回 `null`，页面显示为“—”，不虚构升降名次。

## 模型接入边界

- 浏览器只访问 Node 后端；模型地址、模型名称和密钥继续由后端环境变量管理。
- 助手、路径规划、个性化测验、运行解释仍复用现有服务层与 Agent；模型不可用时沿用后端已有的受控降级逻辑。
- 页面文案只说明学生下一步可以做什么，不展示画像计算、检索链路、知识图谱更新或内部协同方式。
- 后续更换模型时保持上述 HTTP 响应结构，前端无需再次调整页面布局。
