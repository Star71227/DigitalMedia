# 学生端 AI 功能验收

本次沿用现有白色卡片、蓝紫色强调、按钮和测验布局。所有修改直接保存在项目目录中。

1. 路径、资源、学习评估和测验：新增“AI 学习依据”卡片，读取当前账号的资料数、错题数、提问数、路径版本，以及实时模型连接状态；可点击刷新。数量是已保存数据，不代表每次模型使用全部记录。
2. 测验：新增“组卷方式”，保留原题库手动组卷，并接入 AI 个性化生成和联网题源改编。未配置搜索时禁用联网选项；允许课程资料模式仍可能使用已启用的搜索结果。生成后展示依据和题源，直接进入现有计时、答题、交卷、评分、错题记录流程。模型或内容校验失败会显示错误，不创建假题。基础、提高、综合难度沿用原设置。
3. 错题本：新增“滚动复习”，显示到期任务或后续计划，可跳转助手讲解、同类练习；完成复习后选择“还不会／需要提示／已掌握”，保存到后端并显示下次日期。后续任务到期前不可提交效果。
4. 本地知识库：即使课程资料为空，也保留个人资料上传入口。
5. 路径生成、资源生成及学习报告继续使用原有按钮和接口，不额外创建重复流程。

## 验收步骤

启动模型与前后端后，登录学生账号，依次测试资料导入、助手错题图片、路径生成、资源生成、AI 测验生成与交卷，再在错题本查看复习任务并保存掌握程度。模型服务未启动时应显示未连接；搜索未配置时联网选项不可选。

## 当前验证边界

TypeScript 检查与相关后端回归通过。当前执行环境禁止 Vite/esbuild 创建子进程，生产构建未完成，不能把已有 dist 当作本次新页面。若浏览器使用旧静态构建，刷新不会显示新功能；请从普通 Windows 终端启动 Vite 开发服务，或在 frontend-new 中执行 npm run build 后重新启动网页。共享包包含本次源文件，不包含旧 dist。
