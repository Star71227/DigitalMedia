# 故障降级方案

| 场景 | 表现 | 现场处理 | 备用页面 | 讲解措辞 | 赛后修复 |
| --- | --- | --- | --- | --- | --- |
| AI API 不可用 | 生成超时或显示 fallback | 关闭等待，打开确定性生成版本 | 已审核资源版本/Agent 日志 | “主链路设计了确定性回退，当前展示降级结果。” | 查网络、配额、超时和服务端日志，不在台上改 Key |
| 网络中断 | 星火调用失败、页面请求异常 | 保持本地服务；切 AI 关闭模式 | 本地资源、备用视频/PPT | “个性化状态、题库和资源回退不依赖外网。” | 恢复网络并重跑 verify |
| 数据库启动慢 | 健康检查未就绪 | 等待最多预设 30 秒；超时切离线材料 | 架构/PPT/备用视频 | “后端有有界重试和健康门槛，不在未就绪时对外服务。” | 查 MySQL 健康、磁盘与初始化日志 |
| PPTX 生成失败 | 无下载或资源 failed | 不重试多次，打开已验证版本 | PPTX 预览、已下载真实文件 | “文件生成失败不会覆盖已有 approved 版本。” | 查临时目录、25 MiB 限制、OOXML/存储日志 |
| PDF 生成失败 | 报告状态失败/下载不可用 | 展示学生评估 JSON/教师报告历史 | 学生评估页 | “报告内容先由确定性快照生成，PDF 是交付层。” | 检查 Chromium、字体、`%PDF-` 与权限 |
| RAG 无结果 | insufficient evidence/422 | 切已有有引用资源；不生成无依据内容 | 来源与引用面板 | “无证据时拒绝落库，而不是让模型补写。” | 补充合规知识源并重新导入/验证 |
| 浏览器 chunk 加载失败 | 懒加载错误页 | 刷新一次；仍失败换预热标签 | 同功能备用标签/视频 | “前端有 ChunkErrorBoundary，当前切预热页面。” | 清缓存、核对构建资产和 Nginx 缓存策略 |
| 内置账号异常 | 登录失败/账号占用 | 不重置未知库；切已登录标签 | 备用视频/PPT | “seed 会拒绝覆盖同名普通账号，这是安全保护。” | 在确认的示例库执行账号核验、reset/seed/verify |
| demo reset 失败 | 守卫拒绝或半程失败 | 停止操作，不手工删库 | 已验证现有数据 | “reset 有环境和确认值双守卫，拒绝时不绕过。” | 备份后查 is_demo 标记、事务和文件清理结果 |
| 教师端打不开 | 8081 不可达/页面错误 | 留在学生评估，展示教师接口/备用视频 | 学生评估与 PPT 教师页 | “教师价值来自同一真实数据层，当前用已录真实镜头补充。” | 查 teacher-web 健康、Nginx 和 API 权限 |
| Docker 不可用 | docker 命令不存在/引擎未运行 | 使用本机 Node + MySQL 已启动方案或备用视频 | 部署架构页 | “Compose 已静态检查；本机容器实测不冒充已完成。” | 在装有 Engine 的环境补 build、up、卷重启验收 |
| 现场时间不足 | 4:25 仍在资源页 | 立即跳学生评估与教师端，20 秒总结 | PPT 总结页 | “五类资源均有版本证据，下面直接看闭环结果。” | 复盘镜头节奏，缩短滚动和等待 |

共 12 类故障。现场原则是：最多一次刷新/重试，不修改代码、不改数据库结构、不暴露密钥、不把备用视频说成实时操作。
