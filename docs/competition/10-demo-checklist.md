- [ ] 确认 MySQL 健康、磁盘空间和时间正确；记录数据库名称但不录制密码。
- [ ] 后端 `/api/health` 返回健康；学生端 `:8080`、教师端 `:8081` 可访问。
- [ ] 使用当次环境变量中的账号密码登录 `zhangsan` 与 `teacher_demo`；密码不写入材料。
- [ ] 执行 `npm run demo:reset` 前确认非生产环境与确认值；随后 `npm run demo:seed`、`npm run demo:verify`，保存不含敏感信息的结果。

- [ ] 确认 PDF 报告文件头、大小、checksum 与下载权限；准备已验证本地副本。
- [ ] 检查网络；AI 开关、星火 Key 和超时设置只在服务端；准备 `AI_ENABLED=false` 的降级方案。

- [ ] 录屏 1080p/30fps；麦克风峰值不过载，关闭系统提示音；做 20 秒试听。
- [ ] 备用视频、比赛 PPT、已验证 PPTX/PDF、本地资源均离线可用；文件名不含真实个人信息。
