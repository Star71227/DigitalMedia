# 项目总览

## 一句话定位

**智课研伴 LearnMate** 是“面向计算机专业课程的多智能体个性化学习资源生成平台”，以“**会诊断、会生成、会进化**”概括价值。

## 背景、赛题问题与用户

计算机专业学习同时包含概念、算法、代码和持续练习。统一讲义难以反映学生基础、错因和可投入时间；通用 AI 对话又容易停留在一次回答，缺少题目、路径、完成证据和教师观察的持续状态。项目面向计算机专业学生和负责课程教学的教师，响应 A3 赛题对个性化学习资源生成与多智能体学习系统的要求。

## 痛点与方案

| 痛点 | LearnMate 的真实实现 |
| --- | --- |
| 不知道学生“现在处于哪里” | 七维画像、知识点掌握度、错误模式、测验和 CodeLab 记录 |
| 资源千人一面 | 画像、路径阶段、掌握度、错因、题目/练习白名单共同进入生成上下文 |
| AI 内容难追溯 | 数据结构 RAG、引用快照、题目 ID/练习 ID 白名单、规则审核 |
| 学完没有反馈 | 资源进度与完成证据、测验提交、路径阶段评估、学生评估与教师报告 |
| 模型不可用即中断 | 关键资源、路径、反馈和评估均有确定性服务或规则回退 |

## 三大核心价值

- **会诊断**：画像对话、测验、错题、CodeLab、学生概览和评估形成多源证据。
- **会生成**：生成学习讲义、思维导图、真实 PPTX、题库练习包和代码案例；数据结构导图/PPTX 可绑定 RAG 引用。
- **会进化**：画像与路径均版本化；真实测验、错误模式、资源完成证据和已验证 CodeLab 提交可改变后续状态。

## 产品能力

学生端提供登录、首页、画像、学习路径、资源中心、知识问答、测验、错题、CodeLab 和学习评估。教师端提供班级/学生列表、班级和测验分析、学生详情、资源请求、Agent 日志和版本化 PDF 报告。学生概览由 `/api/student/overview` 汇总，评估由 `/api/student/assessment` 输出；教师接口统一位于 `/api/teacher/*`。

多智能体不是八个独立聊天窗口，而是后端编排角色。八个核心 Agent 分别负责画像、资源、审核、路径、测验、反馈、辅导和评估；五类资源另由结构化 ResourceAgent/ReviewAgent 流程执行严格 Schema 与规则检查。

## 技术栈与工程交付

- 前端：两套 React 19 + TypeScript + Vite 应用，学生端含 D3、Motion，双方使用 Recharts。
- 后端：Node.js 24、Express 4、MySQL 8.4、JWT、PptxGenJS、JSZip。
- AI：讯飞星火 HTTP API，可由总开关及路径、资源、审核子开关独立控制。
- 部署：Nginx、三个应用镜像、MySQL、健康检查、非 root 运行、三个命名卷、最小权限 CI 和 Gitleaks。

仓库自带 15 份数据结构知识源；按当前切分和安全检查代码静态计算得到 150 个安全知识块。题库文件含 6 道基础客观题和 60 道开放追问题，CodeLab 文件含 10 个练习。数字是仓库内容口径，不代表生产数据规模。

## 当前完成度与限制

当前基线具备学生端、教师端、八类 Agent、五类资源、数据结构 RAG、测验/错题/CodeLab/路径/评估闭环及交付配置。完成度不使用虚构百分比表达。

已完成独立数字讲师 MVP，包括原创 2D 角色、浏览器语音、音频振幅口型、文字降级、无障碍和独立示例页；尚未深度接入正式资源中心和 PPT 微课主链路。它不是完整 Live2D 商业数字人，也未接入正式课程主页面。

未完成或未验收：任意不可信代码沙箱、实时监考、教师批量任务、复杂 Word/OCR 题库导入、全学科知识库、学校生产部署、真实用户与效果指标、性能压测、专业渗透测试。Dockerfile 和 Compose 已完成静态设计、安全检查和配置解析；由于当前机器缺少 Docker Engine，真实镜像构建、四容器启动、卷重启持久化仍待补充验收。
