# 智课研伴 LearnMate 后端改动说明

> 本次改动核心：把 RAG 知识库从「只有数据结构一门课」扩成 5 门课，并在前端把知识库展示出来；顺带修了本地启动脚本。
> 所有改动都在项目根目录 `D:\Users\29973\Desktop\-`，尚未提交 git。

## 一、知识库扩充（核心改动）

### 1. 后端代码改动（支持多学科）

| 文件 | 改动内容 |
|---|---|
| `backend/src/config/knowledgeSubjects.js`（新增） | 学科白名单：数据结构 / 操作系统 / 计算机组成原理 / 计算机网络 / C语言 |
| `backend/src/services/knowledgePointService.js` | `seedKnowledgePoints` 增加 `subject` 参数（原来写死 `'数据结构'`） |
| `backend/src/services/knowledgeIngestionService.js` | 去掉 `meta.subject !== "数据结构"` 的硬校验，改用白名单；修掉统计只查数据结构的问题 |
| `backend/src/services/knowledgeBootstrapService.js` | 从「只导入 data-structures 一个目录」改成循环导入 5 门课（数据驱动） |
| `backend/src/services/knowledgeRetrievalService.js` | `RAG_SUPPORTED_SUBJECTS` 从 `["数据结构"]` 扩到 5 个学科 |

### 2. 新增知识库内容（4 门课，41 份讲义）

目录都在 `backend/data/knowledge-base/` 下，每门课 = `catalog.json`（知识点图谱）+ 若干带元数据的 `.md` 讲义：

| 学科 | 目录 | 讲义数 | 知识块 | 知识点 |
|---|---|---|---|---|
| 操作系统 | `operating-systems/` | 10 | 77 | 10 |
| 计算机组成原理 | `computer-organization/` | 10 | 70 | 10 |
| 计算机网络 | `computer-networks/` | 10 | 64 | 10 |
| C语言 | `c-language/` | 11 | 80 | 11 |
| 数据结构（原有） | `data-structures/` | 15 | 150 | 64 |

格式完全对齐原有 `data-structures`：CC-BY-4.0 许可、`team_authored`、front matter 含 sourceKey / title / author / publisher / license / version / subject / chapter / language / sourceType。

**说明**：按需求把 Python 换成了 C语言；RAG 白名单里现在没有 Python。

### 3. 导入与验证

- 导入结果：56 份讲义、441 个知识块、105 个知识点，0 失败。
- 实测 5 个学科各问一题（进程线程 / Cache / TCP 三次握手 / C 指针数组 / 死锁），聊天接口全部返回带引用的回答（`deterministic_fallback` + 引用来源）。
- **导入是幂等的**：`.env` 里 `KNOWLEDGE_IMPORT_ON_START=true`，重启后端会自动重新导入；同 sourceKey+version 未变会跳过，改内容要升 version。
- 要加「全新一门课」：建目录 + `catalog.json` + 讲义，并在 `knowledgeBootstrapService.js` 的 `COURSES` 列表里补一条。
