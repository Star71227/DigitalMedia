## 需要教研侧注意的题目本身缺陷（非答案键错误）

1. **C_BASE_032（定义歧义）**：选项 A「只有值传递」与 C「值传递，可用指针模拟引用」同时为真。建议把 A 改为「只有引用传递」或把 C 改为唯一完整表述，消除双正确答案。
2. **19 道模板题（C_BASE_002 ~ C_BASE_020）**：题干为「关于 X 的说法正确的是」，选项 B/C/D 均为「只需要记住名称…/没有边界情况…/与其他知识点没有关联…」这类绝对化错误表述，A 是内容空洞的万能正确项。答案键虽然都正确，但这类题**零区分度、无法测量掌握程度**，建议重写而非保留。
3. **答案分布异常**：40 题中 A 占 21、B 占 14、C 占 5、**D 占 0**，且模板题答案清一色为 A。作为题库使用时易被猜测策略命中，建议打乱选项顺序。
4. **C_BASE_037 的标准层面 caveat**：C 标准并不要求空指针的位表示全 0，仅保证 `0` 转换为空指针且与空指针相等。以 A「0」作答符合教学与工程通例，故不判为错误；若追求严谨，可把题干改为「NULL 在大多数实现中的值」或改为「下列哪个是空指针常量」。
