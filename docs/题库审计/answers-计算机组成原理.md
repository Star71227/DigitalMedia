## 边界情况说明（曾疑似歧义、复核后判为不构成歧义）

- **CO_ADAPT_012（DRAM 刷新开销）**：有「刷新一遍时间正比于行数」与「总刷新位数不变」两种思路，但教材口径是刷新以行为单位、每次刷新占用一个刷新周期，故行数越少开销越小 → B 正确，不是歧义。
- **CO_ADAPT_018（平均访存时间）**：D 82ns 对应「命中与缺失串行叠加」的错误口径，主流公式为 AMAT = 命中时间 + 缺失率 × 缺失代价 → C 正确。
- **CO_ADAPT_042（中断响应的软硬件分工）**：通用寄存器与现场信息由中断服务程序（软件）保存，响应阶段仅硬件保存断点 → A 正确。
- **CO_ADAPT_006**：若把尾数全 0 误当作尾数为 0 则得 0，但 IEEE 754 隐含前导 1，故为 1.0×2² → B 正确。
- **CO_BASE_002 ~ CO_BASE_020（19 道模板题）**：选项本身与题干概念无关，只考「该怎么学」的套话，A 恒为唯一合理表述，答案键无误但题目无知识含量。
