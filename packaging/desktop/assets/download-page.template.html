⬇ 下载安装包

安装包已内置运行环境（Node + MySQL）与云服务器上的全套数据快照（账号、班级、作业、题库、资源、报告完全一致），双击安装即可用：不需要另外装 Docker、Node.js 或数据库，也不需要管理员权限。
装好后桌面会出现两个入口：寻笺 学生端 与 寻笺 教师端。

安装与使用

  1. 双击 {{FILE}}，一路「下一步」完成安装（默认装到当前用户目录，约 540MB）。
  2. 双击桌面上的「寻笺 LearnMate」图标启动。首次启动会自动初始化数据库并导入演示数据，需要 1~3 分钟。
  3. 账号与云服务器一致：用你在云端使用的账号密码登录即可；演示账号 学生 zhangsan / lisi、教师 teacher_demo，密码 LearnMateLocal2026!。
  4. 窗口菜单里可切换学生端 / 教师端、重启服务、配置 AI 模型；关闭窗口即退出并停止后台服务。

卸载

设置 → 应用 → 已安装的应用 → 「寻笺 LearnMate」→ 卸载；或运行安装目录里的 unins000.exe。卸载会一并删除本地数据（数据库、生成的课件与报告）。
