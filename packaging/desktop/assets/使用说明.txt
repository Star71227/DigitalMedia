智课研伴 LearnMate 桌面版 · 使用说明
=====================================

一、怎么打开
------------
桌面和开始菜单里有三个入口：
  · 智课研伴 学生端 —— 学生登录，进入学习工作台
  · 智课研伴 教师端 —— 教师登录，进入教师工作台（班级 / 作业 / 题库 / 学情分析 / 报告）
  · 使用说明       —— 本文件
两个入口打开的是同一个桌面程序（LearnMate.exe），只是启动后进的端不同；
程序窗口菜单「页面」里可以随时在学生端 / 教师端之间切换（教师端会另开一个窗口）。
关闭窗口即退出程序，后台服务（数据库、后端、网页服务）会一并正常停止。

二、账号：与云服务器完全一致
----------------------------
安装包内置了云服务器（http://111.230.111.94:9080）的数据快照，
第一次启动会导入这份快照，因此账号、班级、作业、题库、资源、报告都和在云端看到的一样，
用你在云端使用的账号密码直接登录即可（例如教师账号、你自己的学生账号，密码不变）。

三、数据放在哪
--------------
全部保存在软件安装目录（默认 C:\Users\<你的用户名>\AppData\Local\Programs\LearnMate）：
  data\mysql     内置数据库数据（首次启动由内置快照导入）
  data\storage   资源文件与报告文件
  logs           运行日志（出问题时把这个目录发给开发者）
  seed           安装包自带的云端快照（数据库 .sql + 资源文件），删掉不影响运行
卸载程序默认会一并删除这些数据。

四、功能与 AI
-------------
AI 相关功能（学习助手、个性化路径、讲义/课件生成、图片识别作答等）已按云端的配置开启，
使用与云端同一套大模型接口与模型（GLM）。要换成自己的 Key：
双击安装目录里的「配置AI模型.bat」，填入接口地址 / 模型名 / API Key，然后在菜单里重启后台服务。

代码判题（C 语言题）：启动时自动检测本机 Docker，有 Docker 就开启 docker 执行器（与云端一致），
没有则该项功能不可用（其余功能不受影响）。

五、常见问题
------------
1) 第一次启动比较慢
   首次启动要导入云端数据快照（约 15MB），需要 1~3 分钟；之后每次 10~30 秒。
2) 登录提示用户名或密码错误
   账号与云端一致：请用你在云端用的密码；演示账号见第二节。
   确实忘记密码时，可由教师在教师端「学生管理」里重置，或联系管理员。
3) 提示端口被占用
   程序会自动换端口（学生端 / 教师端各自独立避让），不影响使用。
4) 关闭窗口后任务管理器里还有 mysqld
   稍等几秒会自动退出；若长时间存在，双击安装目录里的「停止智课研伴.bat」。
5) 杀毒软件 / SmartScreen 提示未知发布者
   安装包未做数字签名（比赛作品），选择「仍要运行 / 允许」即可。
6) 装在原来就有数据的目录、或发现账号是旧的演示账号
   菜单「服务 → 导入云端数据（恢复成和云端一致）」可把安装包内置的云端快照重新导入
   （会覆盖本机现有数据，先确认不需要保留）；也可以双击安装目录里的「导入云端数据.bat」。
7) 想彻底删除
   设置 → 应用 → 已安装的应用 →「智课研伴 LearnMate」→ 卸载，或运行安装目录里的 unins000.exe。

六、仍然打不开
--------------
把 logs 目录打包发给开发者即可定位问题。
